# Crescendo — JS Edition

A from-scratch tribute to **LiveUpdate's Crescendo**, the Netscape Navigator plug-in that filled
1990s homepages with MIDI music: full songs in files of a few kilobytes.

Everything is plain JavaScript in one file, `crescendo/crescendo.js`. There are no dependencies and no build step.

- **MIDI file player**: type 0/1/2 Standard MIDI Files, RIFF `.rmi`, and karaoke `.kar` (lyrics scroll in the LCD).
- **Two synthesizers**, both running in an AudioWorklet with sample-accurate sequencing, so music keeps time in background tabs:
  - **FM Synthesis (OPL-style)**: a Sound Blaster-flavoured 2-operator FM synth with all 128 General MIDI patches and a synthesized drum kit, including an 808-style electronic kit. Zero download.
  - **Wavetable**: a SoundFont 2 (`.sf2`) sampler with envelopes, filters, LFOs, loops and exclusive classes. It ships configured for GeneralUser GS. Drop any other `.sf2` onto the player to swap banks.
  - **External MIDI device**: sends the song out over Web MIDI to a real synth, or to FluidSynth/TiMidity.
- GS/GM/XG reset SysEx, RPN pitch-bend range and tuning, sustain pedal, and Freeverb reverb plus chorus (CC91/CC93).
- **The real Crescendo panel**: 200×55 pixels, rebuilt from an archive.org screenshot of the late-90s plug-in (see `reference/`).
  It has the logo, a "Crescendo!" display with a scrolling title or karaoke lyrics, a yellow `00:00.00` counter, a buffer gauge, and a speaker volume slider.
  The buttons are |◀◀ ◀◀10s ❚❚ ■ ▶ 10s▶▶ and a lock, which stops other autostarting music from interrupting the song. Right-click opens a menu with an About box.
- **Legacy markup just works:** `<EMBED>`, `<BGSOUND>`, `<OBJECT>` and plain `<A HREF="x.mid">` links, which open a pop-up player.

## Run it

```sh
./get-soundfont.sh   # only if soundfonts/GeneralUser-GS.sf2 is missing (it ships with the repo)
./serve.sh           # then open http://localhost:8097/
```

The page must be served over HTTP, because browsers block `fetch()` of local `.mid` files from `file://`.

- `index.html` is *The MIDI Lounge*, a GeoCities-style homepage with a jukebox, hit counter, guestbook and sparkle cursor.
- `embed-test.html` is a bare 1997-style page using raw `<EMBED>` / `<BGSOUND>` / `<OBJECT>` tags.

Modern browsers won't play sound until you click or press a key. Autostart players show **CLICK TO PLAY**, and hidden
background music shows a small tooltip. The first click anywhere on the page starts the music.

## Use it on your own page

```html
<script src="crescendo/crescendo.js" data-soundfont="soundfonts/GeneralUser-GS.sf2"></script>

<EMBED SRC="mysong.mid" AUTOSTART=TRUE LOOP=TRUE WIDTH=200 HEIGHT=55>
<BGSOUND SRC="mysong.mid" LOOP=INFINITE>
<crescendo-player src="mysong.mid" autostart loop width="300" height="60"></crescendo-player>
<a href="mysong.mid">Click for music!</a>
```

- Leave out `data-soundfont` to use the FM synth only, with nothing extra to download.
- Add `data-links="off"` to stop `.mid` links from opening the pop-up player.
- Add `data-logo="globe"` to replace the original LiveUpdate logo with an original drawing. Do this before putting the page anywhere public.
- Supported attributes: `src`, `autostart`, `loop` (`true`, `infinite` or a play count), `hidden`, `width`, `height`, `volume` (0–100).
- At 300 px wide or more the Crescendo logo appears. Below 44 px tall the player switches to a compact single row.

The `<crescendo-player>` element has `play()`, `pause()`, `stop()`, `seek(seconds)`, `load(urlOrFileOrArrayBuffer)`,
`setVolume(0..1)`, `currentTime` and `duration`. It fires `load`, `play`, `pause` and `ended` events.
`Crescendo.play(urlOrFile)` opens the pop-up player.

Player controls: drag the speaker or use the mouse wheel to change volume. Space plays or pauses, and ← / → skip 10 seconds.
Drag a `.mid` or `.sf2` file onto the player to load it.
Only one song plays at a time. You had one MIDI device back then, too.

## Tools

```sh
node tools/render.mjs midi/canon-in-d.mid out.wav --sf2 soundfonts/GeneralUser-GS.sf2   # MIDI -> WAV (or --fm)
node tools/make-songs.mjs                                                                # rebuild the demo songs in midi/
```

`render.mjs` runs the exact worklet code from `crescendo.js` offline, so it doubles as the synth's test harness.
It reports peak and RMS levels, clipping and render speed.
